Aplicación: ¿IA o Humano?
Mundial Social 2026 · INNOVATECNM · Etapa Local
Instituto Tecnológico Superior de Lerdo

Archivos principales:
- index.html: actividad para alumnos.
- dashboard.html: resultados para docente.
- questions.js: banco de preguntas.
- styles.css: diseño con colores institucionales tipo guinda, rojo y dorado.
- encabezado.png: encabezado del evento.

Uso local:
1. Abre index.html con Live Server.
2. Los alumnos contestan la actividad.
3. Abre dashboard.html para revisar resultados del navegador.

Importante:
Esta versión guarda resultados en localStorage, es decir, en el navegador donde se responde.
Para que todos los celulares envíen respuestas a un dashboard central, se requiere conectar Firebase/Firestore.
